# pay down the json module

## Summary
`src/json.rs` was the worst file left after the graph split: 138 total excess across four
categories, 491 lines, and seven functions over the cyclomatic limit.

Unlike the three paydowns before it, the split here was obvious from the first read — a JSON
module is a reader and a writer, and they share only the value type. What was less obvious is
that the *reader* is three things, and keeping them together is what made its functions long:

- `cursor.rs` — a position in the input and the five primitives that move it (`peek`, `bump`,
  `skip_ws`, `expect`, `literal`).
- `parse.rs` — the recursive shape: which value comes next, and where a container ends.
- `scan.rs` — the two scalars that have structure of their own, strings and numbers.
- `render.rs` — the other direction, and the only place the byte-level contract lives.
- `mod.rs` — the `Json` value and its four accessors, nothing else.

Five functions were decomposed, and in four cases the decomposition named a rule that had been
implicit:

- **`number` (cyclomatic 16, cognitive 14, 43 lines) is a grammar**, and now reads like one:
  `int_part`, `frac_part`, `exp_part`, over a shared `digits`. The two "commits to a digit"
  rules — a `.` and an `e` must be followed by one — are now one line each in the function that
  owns them, instead of two of six branches in a long one.
- **`string` (cyclomatic 19) separated from `escape`.** The escape table became a `const`
  paired by name with the renderer's, so the two directions can be read against each other; a
  test now walks it and asserts every entry is readable.
- **`object` and `array` shared one decision they each implemented.** `more` is the
  comma-or-closing-bracket step both make, so the two containers can no longer diverge on it.
- **`unicode_escape` grew a `trailing_surrogate`.** The save-and-restore of the position, when
  what follows a high surrogate turns out not to be its pair, was three nested `if`s deep.

## Notes
Every category the file touched improved, and the deltas sum to exactly its former 138:

| category | before | after | delta |
|---|---|---|---|
| `file_lines` | 464 | 364 | −100 |
| `function_cyclomatic` | 241 | 217 | −24 |
| `file_functions` | 176 | 168 | −8 |
| `function_cognitive` | 114 | 108 | −6 |

`src/` drops from 14 files to 13, and `module_files` stays at zero.

**The new test found a real subtlety, by failing.** This module's stated contract is
byte-identity with `json.dumps(obj, ensure_ascii=False)`, and nothing was checking that against
an actual Python. So `render.rs` now carries a corpus of 32 cases whose expected strings —
compact and `indent=2` — were **generated by CPython**, not written by hand.

The first version of that corpus failed on `-0`. The cause was the test, not the engine, and it
is worth recording: **CPython's own round-trip is lossy for numbers.** `json.loads("-0")` is the
int `0`, and `1E+2` is the float `100.0`, so `dumps(loads(x))` is not `x`. This engine keeps a
number's source text on purpose — an engine that never interprets a number must still hand it
back unchanged — so comparing it against Python's round-trip of non-canonical input asserts the
divergence backwards.

The fix makes the property precise, and stronger for it: every corpus source is a **fixed point
of Python's encoder**, which is what any `index.jsonl` written by an engine already is. The
divergence itself is now its own test (`the_token_survives_where_pythons_round_trip_would_not`),
so it is written down rather than waiting to be rediscovered as a mismatch.

**Coverage.** 11 unit tests became 22. Beyond the corpus and the divergence, the additions cover
what the split made nameable: every escape in the table being readable, a truncated or non-hex
`\u`, a lone surrogate not consuming what follows it (three ways), each place a number can stop
short (`1.`, `1e`, `1e+`, `-`, `01`), an unclosed container naming which one it was reading,
whitespace wherever JSON allows it, a duplicate key resolving to the last, and each accessor
declining on the wrong shape rather than guessing.

Behaviour is unchanged: a 35,844-line golden over every `--json` path — `list`, `show`, `deps`,
`ready`, `next` for all 244 issues — plus both committed `index.jsonl` files, byte for byte
identical.
